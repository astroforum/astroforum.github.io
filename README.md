# astroforum.github.io

Astro Lab 홈페이지 소스입니다. 주소: https://astroforum.github.io

- 페이지: `index.html`, `people.html`, `research.html`, `publications.html`, `news.html`, `contact.html`
- 공통 메뉴/푸터: `assets/layout.js`
- 스타일: `assets/style.css`
- 주황색 `[ ... ]` 표시(class="todo")는 실제 내용으로 바꿀 자리입니다.

로컬 미리보기: `python3 -m http.server 8000` 후 http://localhost:8000
