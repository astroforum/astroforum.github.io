# Astro Lab Website

Visit **[astroforum.github.io](https://astroforum.github.io)** 🚀

_Built with [Lab Website Template](https://greene-lab.gitbook.io/lab-website-template-docs)_

- 구성원: `_members/` (한 사람당 파일 하나)
- 논문: `_data/sources.yaml` (DOI만 넣으면 자동 완성)
- 소식: `_posts/` (날짜-제목.md)
- 실제 내용으로 바꿀 자리는 `[ ... ]`로 표시되어 있습니다.
